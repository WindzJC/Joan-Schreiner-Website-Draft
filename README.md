# Joan Schreiner — distinct testimony-inspired concept (revision 2)

A complimentary **book-page concept**, designed to complement Joan's existing website rather than replace it. This is deliberately not a generic author template.

## Creative direction
- **Core metaphor:** broken chains / light through a tear. Art direction derives from the published title, its message, and the release artwork.
- **Visual progression:** deep teal and dusk tones in the opening, repaired gold accents, warm parchment through the story, and final light in the close. No recycled hero/card grid.
- **Layout:** asymmetric immersive hero, three large full-width chapter-like bands, standalone book podium, two-column biography, newspaper-style press index. Typography uses expressive Newsreader headlines, not the prior Playfair-and-cards pattern.
- **Content:** reader-first positioning, no invented quotations or reviews.

## Run
Static HTML/CSS/JS. Open index.html or host the folder root; no build required. `index.html`, `styles.css`, `script.js`, `assets/favicon.svg`, `_headers`, `robots.txt` are included. The bundled `joan-schreiner-preview.html` at /mnt/data is a self-contained local preview, with the same CSS and JS embedded.
